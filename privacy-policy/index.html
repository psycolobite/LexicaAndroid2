Politique de confidentialité

Cette politique décrit comment l'application Lexica collecte, utilise et protège les données liées à votre utilisation de l'application.

Dernière mise à jour : 9 avril 2026

1. Responsable de l'application

Application : Lexica
Éditeur : Paul Mottet
Contact support : mottet2.paul6@outlook.fr

2. Données traitées

Selon les fonctionnalités que vous utilisez, Lexica peut traiter les catégories de données suivantes :

  • données d'authentification (adresse e-mail, identifiant utilisateur) ;
  • données de progression et d'usage dans l'application ;
  • préférences locales et réglages de l'utilisateur ;
  • mots, cartes et contenus ajoutés manuellement dans l'application ;
  • données minimales de synchronisation cloud si vous utilisez un compte.

3. Finalités du traitement

Ces données sont utilisées pour :

  • permettre la connexion à l'application ;
  • sauvegarder et restaurer certaines données liées à votre compte ;
  • synchroniser votre progression entre plusieurs appareils lorsque cette fonction est activée ;
  • personnaliser l'expérience d'apprentissage ;
  • assurer le bon fonctionnement technique de l'application.

4. Base légale du traitement

Les traitements décrits dans cette politique reposent principalement sur les bases légales suivantes :

  • exécution du service pour créer un compte, vous authentifier et synchroniser votre progression lorsque vous utilisez ces fonctions ;
  • votre demande ou votre choix lorsque vous activez des fonctions optionnelles, comme la connexion Google ou la synchronisation cloud ;
  • intérêt légitime pour sécuriser le service, prévenir les dysfonctionnements et assurer la continuité technique de l'application.

5. Authentification et services tiers

Lexica peut utiliser les services tiers suivants :

  • Firebase Authentication pour la connexion par e-mail/mot de passe ou via un compte Google ;
  • Firebase Firestore pour la synchronisation de certaines données de progression ;
  • Google Sign-In si vous choisissez ce mode de connexion.

Ces services agissent comme prestataires techniques nécessaires à l'authentification, à l'hébergement et à la synchronisation cloud. À la date de cette politique, l'application ne déclare pas d'SDK publicitaire intégré ni de SDK d'analytics dédié destiné au profilage publicitaire.

6. Données synchronisées dans le cloud

Lorsque vous utilisez la synchronisation cloud, Lexica peut synchroniser certaines données liées à votre progression, notamment des indicateurs comme l'XP, le niveau, la série de jours, la dernière connexion utile à la progression et certains favoris.

Les données d'apprentissage plus détaillées et le contenu local de l'application peuvent rester principalement stockés sur l'appareil selon les fonctionnalités utilisées.

7. Stockage local

Lexica conserve également des données en local sur votre appareil afin de permettre l'utilisation courante de l'application, notamment la liste des cartes, la progression d'apprentissage et les préférences utilisateur.

8. Suppression du compte et des données

Si vous utilisez un compte, l'application prévoit un flux de suppression du compte depuis l'écran de profil de l'application.

  • la suppression du compte vise à supprimer l'accès au compte connecté ;
  • les données synchronisées associées au compte peuvent être supprimées dans le cadre de ce flux ;
  • les données stockées localement sur l'appareil peuvent également être réinitialisées selon les options utilisées.

Pour toute demande complémentaire relative à vos données, utilisez le contact support indiqué dans cette politique ou dans la fiche Google Play de l'application.

9. Durée de conservation

Les données sont conservées selon les critères suivants :

  • les données liées au compte sont conservées tant que votre compte reste actif, sauf obligation légale contraire ;
  • les données synchronisées dans le cloud sont conservées jusqu'à suppression du compte ou suppression de ces données via les fonctions prévues ;
  • les données locales restent sur votre appareil jusqu'à leur suppression par l'application, leur réinitialisation ou la désinstallation de l'application.

10. Partage des données

Les données ne sont pas revendues. Elles ne sont partagées qu'avec les prestataires techniques nécessaires au fonctionnement de l'application, dans la mesure où vous utilisez leurs services, par exemple Firebase pour l'authentification et la synchronisation.

11. Sécurité

Pour les données synchronisées dans le cloud, Lexica s'appuie principalement sur les mécanismes de sécurité fournis par Firebase et l'infrastructure Google Cloud utilisée par ces services, ainsi que sur les contrôles d'accès applicatifs nécessaires au bon fonctionnement du compte utilisateur.

Ces mesures visent à réduire les risques d'accès non autorisé, d'altération ou de perte des données. Comme pour tout service numérique, un risque résiduel ne peut toutefois pas être totalement exclu.

12. Transferts de données

Certains services techniques utilisés par Lexica, notamment ceux fournis par Google / Firebase, peuvent impliquer un traitement de données en dehors de votre pays et, selon les cas, en dehors de l'Espace économique européen. Lorsque ces services sont utilisés, ces transferts s'effectuent dans le cadre des mécanismes contractuels et organisationnels prévus par leurs fournisseurs.

13. Vos droits

Vous pouvez notamment :

  • demander l'accès aux données vous concernant ;
  • demander la rectification de données inexactes ;
  • demander la suppression de votre compte lorsque cette option est disponible ;
  • demander, selon les cas, la limitation du traitement ou vous y opposer ;
  • demander des informations sur les données liées à votre usage ;
  • cesser d'utiliser les fonctions de synchronisation en vous déconnectant de l'application.

Pour exercer ces droits, vous pouvez utiliser le contact support indiqué dans cette politique.

14. Réclamation auprès d'une autorité de contrôle

Si vous estimez que vos droits ne sont pas respectés, vous pouvez également introduire une réclamation auprès de l'autorité de contrôle compétente, notamment la CNIL pour la France.

15. Évolution de cette politique

Cette politique peut être mise à jour afin de refléter l'évolution de l'application, de ses services techniques ou de ses obligations de publication. La date de mise à jour figurant en haut de page sera modifiée en conséquence.
