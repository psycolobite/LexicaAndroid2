# 🤝 Contribuer à LexicaAndroid2

Merci de vouloir contribuer à ce projet ! 

Ce projet utilise une architecture "Multi-Agents". Si vous êtes un humain ou une IA cherchant à modifier le code, merci de suivre impérativement les guides ci-dessous.

## 📚 Documentation Officielle

Toute la documentation se trouve dans le dossier `docs/`.

### 🚀 Pour commencer
- **[START_HERE.md](START_HERE.md)** : Point d'entrée global.
- **[FEATURES.md](FEATURES.md)** : État des lieux des fonctionnalités.
- **[CHANGELOG.md](CHANGELOG.md)** : Historique détaillé ("Doc Fonctionnelle").

### 🛠️ Règles de Développement
Si vous touchez au code, lisez d'abord :
1. **[Guide d'Installation](docs/guides/SETUP_AGENTS_PARALLEL.md)** : Configuration des éditeurs/agents.
2. **[Guidelines & Standards](docs/guides/GUIDELINES.md)** : Règles Kotlin, Git Flow, Architecture.

### 🤖 Pour les Agents IA
Si vous êtes un agent (Github Copilot, ChatGPT, Claude...), référez-vous à :
- **[Prompts & Rôles](docs/guides/PROMPTS_AGENTS.md)** : Votre définition de tâche.

## 🐛 Signaler un Bug
Vérifiez d'abord **[TROUBLESHOOTING.md](docs/guides/TROUBLESHOOTING.md)** avant d'ouvrir une issue.
