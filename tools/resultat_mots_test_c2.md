# Rapport d'Extraction de Vocabulaire Rhétorique & Débats (C2)
Ce rapport présente les 100 mots de référence qualifiés pour l'objectif **Discussions Soutenues & Rhétorique**.

## Pourquoi sommes-nous limités en nombre de mots ?
1. **Couverture de Lexique.org** : Certains termes de logique formelle ou rhétorique ancienne (ex: *éristique*, *apologue*) ont des fréquences extrêmement basses ou nulles dans le corpus général, limitant leur sélection statistique pure.
2. **Limitation d'accès API Wiktionnaire (HTTP 429)** : Les serveurs Wiktionnaire bloquent temporairement les requêtes rapides automatisées de définitions. Pour contourner cela, le script utilise un dictionnaire de définitions local robuste.
3. **Filtres de Pertinence** : Pour éviter d'inonder l'utilisateur avec du jargon philosophique trop obscur (ex: *hylémorphisme*, *solipsisme*), nous restreignons la liste aux termes réellement exploitables dans un débat structuré moderne.
